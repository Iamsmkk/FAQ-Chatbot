# FAQ Chatbot

This project is a simple FAQ Chatbot developed using Python, Streamlit, and Scikit-Learn.

## Features

* Answer user questions from a predefined FAQ dataset
* Uses TF-IDF Vectorization
* Uses Cosine Similarity for question matching
* Simple and user-friendly interface

## Technologies Used

* Python
* Streamlit
* Pandas
* Scikit-Learn

## How to Run

Install required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py
